The Pipeline

Two agents. One blind evaluation.

Identity and merit never touch the same model. Agent 1 sanitizes; Agent 2 evaluates a payload it has no way to trace back to a person.

01

Raw Submission

A resume, pull request, or code file is dropped into the pipeline exactly as authored.

02

Agent 1 — PII Shield

spaCy NER + Microsoft Presidio locate names, emails, phone numbers, ages, and locations, then redact them in place.

03

Agent 2 — Merit Engine

A local Llama 3 model (via Ollama) scores the sanitized content on quality, structure, and relevance only.

04

Clean Verdict

A structured, bias-resistant breakdown is returned alongside a full redaction audit trail.

Why It's Different

    
Built for trust, not just automation.

    
Every design decision optimizes for one thing: the evaluator should never know who they're evaluating.

  

  

    
Local-First Inference
Ollama + Llama 3 run on your own hardware — no third-party API ever sees raw submissions.

    
Entity-Level Redaction
spaCy NER and Presidio catch names, emails, phone numbers, ages, and locations before scoring begins.

    
Merit-Only Scoring
Agent 2 receives a sanitized payload with no path back to identity, gender, or background.

    
Full Audit Trail
Every redaction decision and score is logged for compliance and appeal review.

    
Bias-Resistant by Design
Separating identity from evaluation measurably reduces demographic and affinity bias in hiring and review.

    
Framework Agnostic
Plug in GitHub PRs, resume PDFs, or plain text through the same two-agent pipeline.
